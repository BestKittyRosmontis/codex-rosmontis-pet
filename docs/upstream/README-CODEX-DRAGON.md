# Codex 白紫 GPT 龙娘

2026-10-03 本机个人使用改编版。基于用户提供的 DSH v0.3.17 功能代码，复用 For-Codex 分支的 Windows 透明窗口与原生跟随实现。不是 OpenAI 官方角色或官方插件。

## 启动与停止

1. 解压整个目录，保持文件结构不变。双击 `Start-Dragon.vbs`，无需管理员权限。
2. 龙娘默认在 Codex 客户区右下角。鼠标移到人物上方显示菜单；单击人物显示气泡；原菜单中的拖拽、缩放和吸附设置可调整位置。
3. 双击 `Stop-Dragon.vbs` 停止桌宠及其监护进程，不会退出 Codex。重新双击启动即可恢复。
4. 双击 `Enable-Autostart.vbs` 注册当前用户登录启动，无需管理员权限。本机交付时已经启用。登录后监护进程等待 Codex，每次打开 Codex 自动显示桌宠，关闭 Codex 后桌宠退出，监护进程低频等待下次启动。
5. 双击 `Disable-Autostart.vbs` 撤销自动启动，不删除设置，也不停止已经运行的桌宠。彻底停止使用 `Stop-Dragon.vbs`；手动停止后，本次登录需再次启动桌宠，或下次登录自动恢复。

自启动入口位于当前用户的 Windows「启动」文件夹，名为 `Codex GPT Dragon Pet.lnk`。它指向本包的启动脚本；移动本包后重新运行 `Enable-Autostart.vbs`。重复启动不会创建多个桌宠实例。不修改系统级启动项或现有 Codex 快捷方式。

底层实现是附属于 Codex 窗口的独立透明窗口，视觉上位于 Codex 内部；不是把网页脚本注入 Codex。它随宿主移动、缩放、最小化和恢复，透明区域不拦截输入。不修改 `app.asar`、WindowsApps 权限、模型、推理强度、网络代理或 Codex 的更新设置。

便携包自带 Electron，不需要安装 Node.js。源码目录需要已有 `node_modules/electron/dist/electron.exe`，开发环境可用 `npm ci` 安装。

## 必须知道的限制

- DSH 的 `deepseekAccount` 账号登录态服务未接入。不能声称“DSH 账号免 Key 查余额”在 Codex 上可用；可用厂商的 API Key 查询是另一条功能。
- API 模板保留不等于所有厂商接口都经过线上验证。此次只对用户指定站点作只读用量查询，并使用用户指定的绘图密钥生成图片；没有遍历厂商或发起付费聊天测试。
- 本机 Token 是本机各会话日志的计数，不只限当前聊天，也不是中转站的账单。复制的分叉历史和归档重复文件做了去重；日志按流读取，单文件超过 512 MiB 会跳过并提示，预算不足会稍后补扫。单条记录超过 2 Mi 字符时只跳过已识别的非计量正文；未知超大记录会标记统计不完整。
- 提问与授权提醒依赖 Codex 是否把相应事件写入日志；未写入的系统提示无法保证捕获。子代理不会冒充主会话完成音效。
- DSH 90 天明细/365 天日汇总归档策略用于金额账本。Codex Token 历史直接取自仍在本机的日志，不会替用户删除或归档 Codex 聊天。
- 本次验证平台是 Windows。保留的 macOS 上游代码未作本次实机验证。
- 龙娘是静态透明插画，按压回弹/翻转为程序动画。导入动图功能仍在。

## 每轮消费入口与口径

人物菜单 → `Codex 用量记录` → `逐轮总消耗`。包含本机所有可读取会话；搜索会话 ID 可缩小到某个聊天。列表最多展示最近 5000 个聚合轮次，分页加载。累计统计不受此显示上限影响。

- Token 来源于 Codex 日志，不是站点账单。缓存是输入的一部分，思考是输出的一部分，不重复相加；只有明确的 root-turn 和父会话关联才合并子代理，无法关联的子代理独立列出。
- 正在进行、已完成、中止、失败及不完整记录会分别标注；截断日志开头的旧累计量归入「未归属用量」，不会算到首个新轮次上。
- `估算金额` 使用当前自定义单价、汇率及现有计价逻辑，不代表当时价格或站点实扣。没有价格、缓存写入价格缺失或记录不完整时保持未知。
- 已验证 `GET /v1/usage` 返回 `usage.today.actual_cost`、余额等汇总。这里使用实际扣费字段，绝不把原价 `cost` 或余额变化冒充每轮实扣。查询结果短时缓存 60 秒。
- 站点的 `GET /api/v1/usage` 是网页登录用户的逐笔账单接口；普通推理 API Key 被拒绝。需要用户在站点正常登录后的授权或账单导出，且需核对逐笔请求与轮次的对应关系，才能可靠合计每轮实际扣费。不会提取浏览器 Cookie、索取账号密码或管理员密钥。
- 只读本机 `logs_2.sqlite` 的 HTTP 响应元数据，以会话、轮次和 `x-client-request-id` 精确核对账单 `client:` ID，不按时间或余额差猜测。实扣仅在已记录请求全部匹配、轮次已结束且计数完整时显示；账单缺失、日志截断、冲突及独立子代理不会冒充完整实扣。
- 初次读取最近最多 200 笔账单，运行期间在内存保留最近 2000 笔。较旧账单不在此范围时仍标记未齐。待入账每约 5 秒重试，已核实余额按 60 秒缓存；同轮更新不重播音效。重启后恢复最近完成轮次，不重播历史提醒。
- 列表是打开时的日志快照，最多有约一分钟延迟。完成一轮后会使快照过期；再次打开用量记录会刷新。长期未关闭的面板不会每秒重扫所有日志。

## 数据与隐私

设置、账本、导入资源和运行状态在 `%USERPROFILE%\.codex\dragon-pet`，不在程序目录。重复启动使用同一实例和同一份设置。

配置的 API 密钥使用 Electron `safeStorage` 加密保存，不支持明文回退。不把生成图片用的密钥写入源码、提示词或便携包。本地 UI 使用自定义协议和带鉴权的命名管道，不开放 TCP 服务。桌宠会读取本机 Codex 日志以统计用量，统计缓存不保存提示词或回复正文。站点汇总在后台读取当前 Codex 凭据，仅发往已授权的固定域名，拒绝重定向；不把密钥或原始响应发送到前端。请勿分享整个运行数据目录或真实会话日志。

## Codex 更新后

本版不覆盖 Codex 文件，不会阻止正常更新。Windows Store 安装路径按应用包前缀识别，不绑定旧版本目录。未来应用若更改窗口结构或日志格式，仍可能需要适配，不能保证永久兼容。

自定义便携 Codex 如果更换了 EXE 位置，可执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Start-Dragon.ps1 -Stop
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Start-Dragon.ps1 -CodexPath "D:\YourCodex\app\ChatGPT.exe"
```

保留 `.codex\dragon-pet` 即保留自定义设置。不要运行目录中上游的旧安装脚本来安装本改编版。
